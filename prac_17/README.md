# 📝 Практические занятия №13-17
Обзор выполненных работ
В рамках практических занятий №13-17 было разработано PWA-приложение для заметок с полным офлайн-режимом, WebSocket-синхронизацией и push-уведомлениями.

## Практическое занятие №13 — Service Worker
Выполненные требования:
✅ Регистрация Service Worker в приложении

✅ Кэширование статических ресурсов (HTML, CSS, JS)

✅ Перехват сетевых запросов через fetch событие

✅ Стратегия Cache First для статики

✅ Полная работа приложения в офлайн-режиме

✅ Сохранение заметок в localStorage

Результат:
Приложение загружается и работает без интернета, заметки сохраняются локально.

## Практическое занятие №14 — Web App Manifest
Выполненные требования:
✅ Создан файл manifest.json с полями:

name, short_name, start_url, display

background_color, theme_color, description

icons (8 размеров: 72x72 до 512x512)

✅ Подключен манифест через <link rel="manifest">

✅ Добавлены мета-теги для iOS:

apple-mobile-web-app-capable

apple-mobile-web-app-status-bar-style

apple-touch-icon

✅ Обновлен Service Worker для кэширования иконок и манифеста

Результат:
Приложение можно установить на устройство (ПК/Android/iOS), оно запускается в отдельном окне без адресной строки.

## Практическое занятие №15 — HTTPS + App Shell
Выполненные требования:
✅ Настроен локальный HTTPS с помощью mkcert

✅ Сгенерированы сертификаты (localhost.pem, localhost-key.pem)

✅ Реализована архитектура App Shell:

index.html — только каркас (шапка, меню, контейнер)

Динамические страницы в папке content/ (home.html, about.html)

Загрузка контента через fetch()

✅ Service Worker кэширует App Shell (Cache First)

✅ Динамический контент загружается по стратегии Network First

Результат:
При мгновенно отображает каркас при загрузке, контент подгружается асинхронно. HTTPS включен для работы Service Worker.

## Практическое занятие №16 — WebSocket + Push (Часть 1)
Выполненные требования:
✅ Создан Node.js сервер с express и socket.io

✅ Реализовано WebSocket-соединение между клиентом и сервером

✅ Клиент отправляет событие newTask при добавлении заметки

✅ Сервер рассылает taskAdded всем подключенным клиентам

✅ Реализованы VAPID-ключи для push-уведомлений

✅ Созданы эндпоинты /subscribe и /unsubscribe

✅ Добавлены кнопки "Включить/Отключить уведомления"

✅ Push-уведомления отправляются при добавлении новой заметки

Результат:
При добавлении заметки все открытые вкладки получают уведомление через WebSocket, а также приходит системное push-уведомление.

## Практическое занятие №17 — WebSocket + Push (Часть 2)
Выполненные требования:
✅ Полная интеграция WebSocket в основное приложение

✅ Отображение всплывающих уведомлений при получении taskAdded

✅ Автоматическое обновление списка заметок при получении от других клиентов

✅ Обработка ошибок push-подписок (удаление невалидных)

Результат:
Приложение полностью готово к работе в реальном времени с несколькими пользователями и push-уведомлениями.
